
# Cars Dealership Review & Management System

## Project Overview

The Cars Dealership Review & Management System is a full-stack web application that allows users to explore dealership branches across the United States, view dealership information, and share customer reviews.

The application provides user registration and login, dealership search and filtering, review submission, and sentiment analysis of customer feedback.

## Project Objectives

- Display dealership locations and details.
- Allow users to register and log in.
- Retrieve dealership information through REST APIs.
- Display reviews for individual dealerships.
- Allow authenticated users to submit reviews.
- Analyze review sentiment.
- Build a responsive frontend.
- Automate testing and deployment using GitHub Actions and cloud deployment tools.

## Technology Stack

- Frontend: React, HTML, CSS, JavaScript
- Backend: Python, Django, Django REST Framework
- Database: SQLite for local development
- Version Control: Git and GitHub
- CI/CD: GitHub Actions
- Deployment: Docker and IBM Cloud Code Engine, subject to environment availability

## Main Features

1. User registration and authentication
2. Dealership listings and state-based filtering
3. Dealership details and customer reviews
4. Review submission
5. Review sentiment analysis
6. Automated workflow and cloud deployment

## Project Structure

The project will contain a Django backend, frontend components and static pages, API endpoints, tests, and deployment configuration.
